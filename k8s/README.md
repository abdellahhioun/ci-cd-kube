# Kubernetes Deployments Placeholders

Ce dossier contiendra les manifests Kubernetes (YAML) pour le déploiement de l'application Hono.

## Manifestes à venir :
- `deployment.yaml` : Définition du déploiement de l'application (pods, répliques, ressources, etc.).
- `service.yaml` : Exposition de l'application à l'intérieur du cluster.
- `ingress.yaml` : Exposition de l'application vers l'extérieur (reverse proxy et routage DNS).

*Le déploiement automatique de ces manifestes sera géré dans la pipeline CI/CD lors de la phase Kubernetes.*
